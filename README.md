# Saloni Furniture

Premium furniture catalogue (no cart or checkout). React + Vite, Tailwind CSS v4, Framer Motion, Lenis, Supabase, EmailJS.

## Run
    npm install
    cp .env.example .env   # then fill in the values
    npm run dev            # http://localhost:5173
    npm run build          # production build in dist/

## Supabase
1. Create a project at supabase.com. Copy the Project URL and anon public key into `.env` (VITE_SUPABASE_URL, VITE_SUPABASE_ANON_KEY). Never use the service-role key.
2. SQL Editor: run `supabase/migrations/001_init.sql`, then `002_map_location.sql`, `003_theme_fonts.sql`, `004_owner_features.sql`, `005_tier2_tier3.sql` and `006_page_builder.sql` (tables, Row Level Security, `product-images` storage bucket).
3. Authentication > Users > Add user (email + password). In Authentication settings, turn off public sign-ups.
4. Make that user an admin (SQL Editor): `update public.profiles set is_admin=true where id=(select id from auth.users where email='YOU@EXAMPLE.COM');`
5. Open `/admin` and log in.

## EmailJS
Create a service and an email template at emailjs.com. The template can use these variables: `{{name}}`, `{{email}}`, `{{phone}}`, `{{message}}`, `{{product}}`, `{{reply_to}}`. Put the Service ID, Template ID and Public Key in `.env`.

## Admin guide
Categories first, then Products (add images and specifications after the first Save; set Status to Published). Homepage, Carousel and Business settings control the public pages. Nothing is hardcoded: sections with no content stay hidden.

## Deploy (Vercel or Netlify)
Import the repo, build command `npm run build`, output `dist`. Add the five environment variables in the host's settings. SPA rewrites are included (`vercel.json`, `public/_redirects`). Add the deployed URL to Supabase Authentication > URL Configuration.

## Themes and fonts
Admin > Design lets the owner pick one of 12 colour themes and a heading and body font. The change previews instantly and applies to the whole site after Save.

## Owner features (migration 004)
- **Enquiries**: every contact-form message is saved in Supabase and shown in Admin > Enquiries (status new / contacted / closed, private notes). Email via EmailJS still works as a second copy. A hidden honeypot field and a minimum-time check reduce spam.
- **Image compression**: photos uploaded in the admin are resized to max 2000px and converted to WebP in the browser.
- **Texts**: Admin > Texts changes menu, button, heading and form wording. Empty means default.
- **Brand**: logo, favicon, Instagram / Facebook / YouTube links, announcement bar.
- **SEO**: Admin > SEO (home title, description, share image) and optional per-product title and description.
- **WhatsApp / Google previews** (Vercel only): `api/seo.js` adds the right title, description and photo to product and category links; `/sitemap.xml` and `/robots.txt` are generated by `api/sitemap.js`. On Netlify these functions do not run; the site still works, only the link previews fall back to the generic ones.
- **Supabase keep-alive**: Vercel Cron calls `/api/keepalive` daily (see `vercel.json`) so a free project is less likely to be paused for inactivity. Check Supabase's current free-plan policy; this reduces the risk but is not a guarantee.
- **Faster public site**: the admin code is loaded only when someone opens /admin.

## Adding the owner as admin
Supabase > Authentication > Users > Add user (owner's email + password), then run the `update public.profiles set is_admin=true ...` SQL with that email. See OWNER_GUIDE.md for the owner's day-to-day instructions.

## Migration 005 features (run 005 BEFORE deploying this code)
- **Enquiry list**: visitors tap the heart on products, review the list at `/saved`, and send one enquiry. Stored in the browser only.
- **Catalogue filters**: built automatically from product specifications (for example Material, Colour). A label needs at least 2 products and 2 to 12 different values.
- **Drag-and-drop reorder** in admin lists and product photos (arrows still work on touch screens). Bulk publish / draft / archive, and duplicate product.
- **Hero slideshow and video**, **product video**, **loading skeletons** and blur-up images.
- **Custom theme**: Admin > Design > Custom colours, with a readability (contrast) check.
- **Product fields**: badge, price text, dimensions; **Preview** link for drafts; photo descriptions (alt text).
- **Testimonials** tab. Hidden on the site until one is added.
- **3D / AR**: upload a `.glb` on a product. Uses Google's `<model-viewer>` loaded from `ajax.googleapis.com` only when a visitor taps the button.
- **Showroom visit form** at `/visit`; requests appear in Admin > Enquiries with a Visit badge.
- **English / Hindi switch**: tick it under Admin > Brand. Site wording (buttons, headings, forms) is translated; product names and descriptions stay as typed. Edit Hindi wording in Admin > Texts.
- **Analytics** tab: private, anonymous counts (product views, saves, WhatsApp and Enquire clicks, enquiries, visits).
- Videos and 3D files use the same Supabase storage bucket. The free plan allows about 50 MB per file and 1 GB in total.

## Migration 006: page builder and interactions (run 006 BEFORE deploying this code)
- **Admin > Home layout**: reorder, hide and delete home page sections, and add new ones (heading and text, photo with text, gallery, video, banner, cards, FAQ, products, spacer). The top banner always stays first.
- **Admin > Pages**: create extra pages (shown at `/p/your-address`, included in the sitemap and link previews).
- **Admin > Menu**: add, remove, rename and reorder top-menu and footer links. Links can point to pages, categories or any website.
- **Admin > Contact form**: add, remove and reorder the form's questions (short/long text, email, phone, number, date, choose-from-list, tick box). Answers to extra questions are appended to the message that is saved and emailed. The Name, Email, Phone, Product and Message fields are the standard ones; `(no name)` / `(not given)` are stored if a visitor is never asked for them.
- **Buttons**: new animated buttons (pill turns into a rounded square, colour fills from the centre, arrow swaps sides, text slides). See `.btn` in `src/index.css`. Touch screens only get the pressed effect.
- **Mouse and scroll**: custom cursor ring with labels (desktop mouse only, off for reduced motion), 3D tilt on product cards, hero mouse parallax, animated menu underlines, parallax photos, scroll-driven big text band, headings that slide up, carousel that speeds up and reverses with your scrolling, header that hides when scrolling down, and a back-to-top button with a progress ring.
